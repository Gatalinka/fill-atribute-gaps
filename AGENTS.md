# Agent Guide

This repo contains a QGIS plugin for interpolating missing numeric attribute
values between known key points.

## Commands

- Inspect plugin entrypoints in `fill_attribute_gaps.py`, `dialog.py`, and
  `interpolate.py`.
- Run available Python or QGIS plugin tests when present.

## Boundaries

- Do not commit generated QGIS project files, local datasets, `.agent/`, or
  credentials.
- Keep changes focused on plugin behavior, metadata, docs, or tests.
